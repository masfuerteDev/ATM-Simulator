# ATM Simulator (Банкомат)

Консольное приложение на Java, симулирующее работу банкомата.

## Возможности
- ✅ Авторизация по 4-значному PIN-коду (5 попыток)
- ✅ Проверка баланса счета
- ✅ Пополнение счета
- ✅ Снятие наличных с проверкой достаточности средств
- ✅ История всех операций с датой и временем

## Как запустить

```bash
javac src/*.java
java src/model.Main
